<h1 align="center">Zahl</h1>

<p align="center">
Zahl is a plain-text calculator for Mac: type what you want to work out in plain language, and the answer appears beside each line. This repository is where Zahl gets its updates: each release here is offered automatically to every copy of Zahl downloaded from monokern.app (the App Store version updates through the App Store). To get Zahl, go to <a href="https://monokern.app/zahl">monokern.app/zahl</a>.
</p>
